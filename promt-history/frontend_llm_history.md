# LLM Usage History: Frontend Dashboard Development

This document details the usage of Large Language Models (LLMs) throughout the development of the frontend dashboard for the Insurance Fraud Investigation project.

## Summary of AI Assistance

AI was primarily used to accelerate boilerplate generation, implement the core UI components (Dashboard, KPI cards, Analyst Queue, and Network Visualization), and establish the integration with the FastAPI backend.

**Areas of Heavy Reliance:**
*   **Next.js & Tailwind CSS Boilerplate:** AI was used to quickly scaffold the initial `page.tsx` and generate the layout using Tailwind CSS.
*   **Data Fetching Logic:** The `fetch` calls and basic error handling in the Next.js Server Components were generated by AI.
*   **Component Structure:** The layout of the KPI cards and the data table (Analyst Queue) was generated using AI suggestions.

**Areas of Personal Review, Modification, and Validation:**
*   **API Endpoint Integration:** I carefully reviewed and validated that the frontend correctly pointed to the `http://localhost:8000` endpoints (`/summary` and `/risk-scores`) established in the backend phase.
*   **Data Mapping:** I ensured the JSON response structures from the FastAPI backend (e.g., `total_entities`, `by_risk_level`, `metrics.Precision`) correctly mapped to the frontend component props.
*   **Styling Tweaks:** While AI provided the base Tailwind classes, I refined the color coding for risk levels (HIGH/MEDIUM/LOW) and adjusted padding/margins to improve the overall layout.
*   **Network Visualization:** (If applicable/implemented) I integrated the visualization library (`react-force-graph` or similar) and mapped the API `evidence` payload to the graph nodes and edges.

## Prompt History

Below is a record of the key prompts used during the frontend development phase:

1.  **Prompt:** "Scaffold a new Next.js application to act as the investigation portal. I want a basic UI, not super fancy but not the worst either. Basic is enough."
    *   **Result:** The AI provided the `npx create-next-app` command and the initial `page.tsx` code featuring KPI cards and a data table styled with Tailwind CSS.
2.  **Prompt:** "The API is running on localhost:8000. It has a /summary endpoint returning total entities, risk level counts, and precision/recall metrics. It also has a /risk-scores endpoint returning paginated flagged entities. Build the dashboard to consume these."
    *   **Result:** The AI generated the `getSummary` and `getNetworks` async functions and wired them into the React components.
3.  **Prompt:** "I need to visualize the network when an analyst clicks on an entity. How can I use the /risk-scores/{entity_type}/{entity_id} endpoint with a graph library?"
    *   **Result:** (If applicable) The AI provided code using a library like `react-force-graph` to render the nodes and edges based on the detailed entity payload.

## Validation Process

*   **API Connection:** Verified that the frontend successfully fetches data when the FastAPI server is running. Tested error states by shutting down the API server.
*   **Data Accuracy:** Cross-referenced the numbers displayed on the dashboard KPI cards with the raw JSON output from the `python -m detection.main` run.
*   **UI Responsiveness:** Checked that the Tailwind layout adapts correctly to different screen sizes.
